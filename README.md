# Foco Leitura

Projeto da **Squad 3** para a atividade “Recursos de Acessibilidade em JS”. A aplicação oferece um modo de leitura customizável para pessoas com TDAH, dislexia ou dificuldades de atenção e processamento de informações.

## Funcionalidades

- escolha entre três tipos de fonte;
- ajuste do tamanho do texto e do espaçamento entre linhas;
- modo foco para reduzir distrações;
- régua de leitura controlada pelo cursor, toque ou atalho `Alt + R`;
- modo de alto contraste;
- indicador de progresso da leitura;
- preferências salvas no navegador;
- navegação completa por teclado e avisos acessíveis de mudança.

## Tecnologias

- HTML5 semântico;
- CSS3 responsivo;
- JavaScript Vanilla;
- ARIA para comunicar mudanças aos leitores de tela.

## Como instalar

1. Baixe ou clone este repositório.
2. Abra a pasta `dist`.
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências.

## Como usar

Use o painel “Ajustes de leitura” para alterar fonte, tamanho, espaçamento, modo foco, régua e contraste. Todos os controles funcionam com a tecla `Tab`. O atalho `Alt + R` liga ou desliga a régua de leitura.

## Testes sugeridos

1. Navegue por todos os controles usando somente `Tab`, `Shift + Tab`, setas, `Espaço` e `Enter`.
2. Aumente o zoom do navegador para 200% e confira se o conteúdo continua legível.
3. Ative o NVDA ou VoiceOver e confirme se as mudanças são anunciadas.
4. Teste no computador e no celular.
